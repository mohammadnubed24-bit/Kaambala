# KaamWala – Home Repair Service App

Flutter starter app for booking local home-repair services such as electricians and carpenters.

## Project structure
- `lib/` – Flutter application code
- `android/` – Android platform project
- `pubspec.yaml` – Flutter dependencies and app metadata

## Run
1. Install Flutter SDK.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Connect an Android device/emulator.
5. Run `flutter run`.

This is a starter/prototype. OTP authentication, backend/database, maps, payments, notifications, and real-time provider tracking still need to be connected before production release.
