# KaamWala – Home Repair Service

Starter Flutter app for a Carpenter + Electrician service marketplace.

## Included
- Customer home screen
- Electrician / Carpenter categories
- Service selection
- Booking form
- Booking status screen
- Provider dashboard
- Admin dashboard
- Local demo data (no backend yet)

## Run
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Run `flutter run`.

This is a functional starter/prototype. Production features such as OTP authentication,
maps, real-time provider tracking, payments, notifications, and a secure backend need
to be connected before publishing.
